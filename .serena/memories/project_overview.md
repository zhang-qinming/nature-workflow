# Project overview
- Purpose: config-driven orchestration for a paper pipeline covering GeneBayes, Perturb-seq data preparation, legacy plotting, and a newer reusable `figures` rendering layer.
- Main entrypoint: `paper-pipeline` CLI from `src/paper_pipeline/cli.py`.
- Tech stack: Python 3.10+, YAML config, R scripts for rendering/statistics, shell generators for Slurm submission.
- Structure:
  - `src/paper_pipeline/dataprep`: core workflow/task/config system plus GeneBayes and Perturb-seq dataprep.
  - `src/paper_pipeline/plot`: legacy paper reproduction plotting workflows/scripts.
  - `src/paper_pipeline/figures`: newer reusable figure workflows that consume stable outputs directly.
  - `configs`: default/example YAMLs and mapping files.
  - `docs`: workflow and batch-script docs.
  - repo root generators: `generate_run_once_batch_scripts.sh`, `generate_trait_batch_scripts.sh`, `generate_plot_batch_scripts.sh`, `generate_figure_sbatch.sh`.
- Current design direction: keep `plot` as legacy reproduction layer; put reusable, batch-friendly rendering in `figures`.
