# 全流程数据描述（按代码流程顺序）

本文档按 workflow 执行顺序描述各阶段的输入/输出文件格式、必需字段与关键约束。代码依据：`src/paper_pipeline/dataprep/workflows/`、`src/paper_pipeline/plot/workflows.py`、`src/paper_pipeline/figures/workflows.py`。

## 0. 全局约定

### 路径解析

- `inputs.*` / `outputs.*` 相对路径以**配置文件所在目录**为基准解析
- `project_root` 与 `artifact_root` 也按配置文件所在目录解析
- 未显式配置输出路径时，产物默认落在 `artifact_root`（默认 `outputs/`）
- 仓库模板配置在 `configs/`，指向仓库根 `data/` 的路径写成 `../data/...`；若复制到仓库根运行请改回 `data/...`

### 占位符

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{artifact_root}` | 输出根目录 | `outputs` |
| `{trait_label}` | trait 标签（常与 posterior 文件名一致） | `Backman_2021_86` |
| `{trait_file}` | GeneBayes posterior 文件名 | `Backman_2021_86.per_gene_estimates.tsv` |
| `{cell_type}` | cNMF essential cell type | `K562_essential_raw_singlecell_01` |
| `{k}` | cNMF program 数 | `60` |
| `{threshold}` | consensus_density_threshold 标签化 | `0.4 -> 0_4` |
| `{worker_index}` | factorize worker 编号（0 开始） | `0` |
| `{program_index}` | program 编号（1 开始） | `1` |

### ID 与列名约定

- cNMF `gene_spectra_score`、GeneBayes posterior、shet 表按 `ensg`（无版本号的 `ENSG...`）对齐
- gene-level `metadata.csv` 的 `gene` 列是 perturbation 靶点（gene symbol），`non-targeting` 是对照标签
- 部分 R 脚本会去掉 Ensembl 版本号（按 `.` 分割取第一段），因此所有文件都应用无版本号的 `ENSG...`

### TSV/CSV 读取方式

- R 侧 `read.csv(..., row.names=1)`：第一列被当作行名（必须唯一、可对齐）
- R 侧 `data.table::fread(..., header=TRUE)`：默认按逗号/制表符读取
- Python 侧 `adata.to_df().to_csv(...)`：cell barcode 写成第一列（CSV index）

推荐细粒度链见 `docs/全流程运行说明.md`。

## 2. 阶段 A：GeneBayes

三条入口（共用 `workflows.genebayes.*` 配置）：
- `genebayes`：prediction + merge + training（全链）
- `genebayes-cpu`：prediction + merge（不做 training，不需要 train/val gene list）
- `genebayes-gpu`：只 training（需要 `features.{trait_label}.tsv` 已存在）

### 输入

| 配置键 | 格式 | 必需字段 |
|--------|------|----------|
| `inputs.s_het` | TSV (`\t`) | `hgnc`, `ensg`, `chrom`, `post_mean` |
| `inputs.reduced_embeddings` | **空格**分隔 | `gene` + embedding 数值列 |
| `inputs.celltype_ntpm` | TSV (`\t`) | `ensg` + 特征列 |
| `inputs.geneformer_mixture` | TSV (`\t`) | `ensg` + 特征列 |
| `inputs.traits_dir/{trait_label}.summary_statistics.csv` | CSV (`,`) | `ensg`, `beta`, `standard_error` |
| `inputs.train_gene_list` | 每行一个 `ensg` | — |
| `inputs.val_gene_list` | 每行一个 `ensg` | — |

### 输出

| 路径 | 说明 |
|------|------|
| `{artifact_root}/genebayes/posterior/{trait_label}.per_gene_estimates.tsv` | 主结果：`ensg`, `prior_mean`, `post_mean`, `lower_95`, `upper_95` |

### 常见坑

- 训练参数 `--integration_lb` / `--integration_ub` 必填
- 训练时 `features` 和 `response` 按 `ensg` 取交集
- 启用 early stopping 时必须同时提供 train/val gene list

## 3. 阶段 B：Perturb-seq gene-level

对应：`prepare` → `limma` → `summarize`

### 输入

| 配置键 | 格式 | 关键约束 |
|--------|------|----------|
| `gene_level.inputs.h5ad` | AnnData | `var_names` 建议为 `ensg` |
| `gene_level.inputs.metadata` | CSV (`,`) | **第一列必须是 cell_barcode**（`read.csv(row.names=1)`）；必须含 `gem_group`, `n_genes`, `mitopercent`, `gene` |

`metadata.csv` 的 `gene` 列中对照细胞标为 `non-targeting`。

### 输出

| 子步骤 | 产物 | 说明 |
|--------|------|------|
| prepare | `limma_input/{chunk}.input` | TSV，首列 `cell_barcode`，末尾固定 6 列：`gem_group, n_genes, mitopercent, leiden, gene, GROUP` |
| limma | `gwps_limma/{GENE}_KO.txt` | TSV，首列 `GENE`（被检验的表达基因），含 `logFC`, `P.Value`, `adj.P.Val` |
| summarize | `K562GW/limma_logFC_sum.txt` | 矩阵：行=表达基因(`GENE`)，列=扰动靶点 |

### 常见坑

- `.input` 末尾必须恰好 6 个固定列（`limmatrend.R` 用 `N <- ncol(df_all) - 6` 切表达列）
- metadata 的 cell barcode 必须与 count 矩阵一致
- gene ID 建议统一为 `ensg`

---

## 4. 阶段 C：cNMF essential

对应：`prepare → factorize → postbase-base → postbase-regulation → association`

### 输入

| 配置键 | 格式 | 说明 |
|--------|------|------|
| `cnmf_essential.inputs.h5ad_dir/{cell_type}.h5ad` | AnnData | 每个 cell type 一个 |
| `cnmf_essential.inputs.metadata_dir/{cell_type}_metadata.csv` | CSV | 同 gene-level metadata 格式 |
| `cnmf_essential.inputs.gene_map` | 2 列无表头 | `<ENSG> <gene_symbol>`，空白分隔 |
| `cnmf_essential.inputs.shet_path` | TSV | `ensg`, `shet`, `shet_BIN` |
| `cnmf_essential.inputs.lof_dir/{trait_file}` | TSV | GeneBayes posterior（默认从 genebayes artifact 解析） |

### 关键默认参数

`k=60`, `total_workers=20`, `n_iter=100`, `seed=14`, `numgenes=2000`, `consensus_density_threshold=0.4`, `random_iterations=100000`

### 关键输出

| 产物 | 路径模式 |
|------|----------|
| usages | `cNMF/{cell_type}/test1/test1.usages.k_{k}.dt_{threshold}.consensus.txt` |
| GEP | `cNMF/{cell_type}/test1/test1.gene_spectra_score.k_{k}.dt_{threshold}.txt` |
| 调控效应 | `cNMF_regulation/{cell_type}/K{k}_program{program_index}_perturb_effects.txt`（列：`GENE`, `lm_es`, `lm_p`） |
| association | `trait_association/{cell_type}/ProgramLevel/regulators_enrichment_K{k}_{trait_file}` |

---

## 5. 阶段 D：cNMF genomewide

对应：`prepare → factorize → postbase-base → postbase-regulation → association`

与 essential 的区别：
- 单 h5ad（非多个 cell type）
- `ks = [30, 60, 90, 120]`，`association_k = 60`
- `total_workers = 200`
- `consensus_density_threshold = 0.5`（文件名 `dt_0_5`）
- 多个 per-K run 的 `cnmf_tmp` 合并到聚合 run（默认 `cNMF_all`）

输出：`trait_association/K562GW/ProgramLevel/regulators_enrichment_K60_{trait_file}` 和 `programs_enrichment_K60_{trait_file}`

### 常见坑

- 阈值标签：genomewide 默认 `dt_0_5`；plot 脚本硬编码读取 `dt_0_5`，改阈值会导致 plot 阶段找不到文件

## 6. 阶段 E：Plot

四条 plotting workflow 的共同特征：
- 在 `outputs/plots/` 创建 legacy 兼容工作区，通过软链接/拷贝挂接上游产物
- 执行 `src/paper_pipeline/plot/scripts/` 下的包内脚本
- 自动产出 `workflow_manifest.md` 和 `stage_inventory.tsv`

### `plot-gene-burden`（Figure2）

链接的关键输入：GeneBayes posterior、raw burden、GWAS（含 `{trait}_irnt.tsv.gz`）、geneset、gene_map

GWAS 文件格式（`{trait}_irnt.tsv.gz`）：必须含 `variant`（`CHR:POS:REF:ALT`）、`pval`；可选 `low_confidence_variant`

### `plot-perturbseq-gene-level`（Figure3）

链接的关键输入：gene-level limma 汇总、GeneBayes posterior、GWAS、shet

### `plot-perturbseq-cnmf`（Figure4/5）

链接的关键输入：genomewide cNMF 产物、GeneBayes posterior、GWAS、trans-eQTL（gzip TSV，至少含 `SNP`, `SNPChr`, `SNPPos`, `AssessedAllele`, `Zscore`, `Gene`, `GeneSymbol`）

### `plot-supplementary`

链接的关键输入：LDSC 资源、TF ChIP、K562GW 结果、multi-cell 根目录。额外依赖 `ldsc_*_reference_dir` 系列外部参考目录。

## 7. 开跑前数据自检

1. GeneBayes：抽一个 trait，检查 `per_gene_estimates.tsv` 含 `ensg` 与 `post_mean`
2. gene-level：metadata 第一列为 cell barcode；`.input` 以 `cell_barcode` 开头、以 6 个固定列结尾
3. cNMF genomewide：确认 `cNMF_all.gene_spectra_score.k_{association_k}.dt_0_5.txt` 存在
4. Plot：先看 `workflow_manifest.md` 确认所有输入 `exists: yes`
